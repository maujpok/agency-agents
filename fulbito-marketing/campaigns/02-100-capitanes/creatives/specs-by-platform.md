# SPECS TÉCNICAS POR PLATAFORMA — 100 Capitanes Fulbito
## Formatos, resoluciones, duraciones y límites de caracteres

---

## TIKTOK

### Videos
| Spec | Valor |
|---|---|
| Formato | MP4 / MOV |
| Ratio | 9:16 (vertical) — obligatorio |
| Resolución | 1080 × 1920 px mínimo. 4K si es posible (2160 × 3840 px) |
| Duración óptima | 15–30 segundos (campaña teaser). Nunca más de 60s en esta campaña. |
| FPS | 30fps mínimo. 60fps si el dispositivo lo permite. |
| Bitrate | 25 Mbps recomendado |
| Tamaño máximo | 287.6 MB |
| Zona segura | Dejar 150px libres en la parte inferior (zona del caption, botones de interacción) y 100px en los lados (botones de acción) |
| Zona del hook | Los primeros 3 segundos: texto centrado en el 40–60% superior de la pantalla |

### Captions
| Spec | Valor |
|---|---|
| Límite de caracteres | 2.200 caracteres |
| Hashtags | 3–5 hashtags. No más. El algoritmo de TikTok es semántico, no de hashtags. |
| Posición del CTA | Al inicio del caption o al final. No en el medio. |
| Mención de "link en bio" | Permitida y recomendada. El link se pone en el perfil (1 link máximo). |

### Audio
| Spec | Valor |
|---|---|
| Formato | AAC / MP3 |
| Bitrate | 128 kbps mínimo |
| Duración | Debe coincidir con la duración del video |
| Derechos | Usar solo audios de la biblioteca de TikTok o música libre de derechos. Si se usa trending sound, verificar que esté disponible comercialmente. |

### Frecuencia de publicación sugerida
- Semana 1: 1 video
- Semana 2: 1–2 videos (lunes/martes y jueves/viernes)
- Semana 3: 2–3 videos (urgencia requiere más frecuencia)
- Semana 4: 1 video

## INSTAGRAM

### Stories
| Spec | Valor |
|---|---|
| Formato imagen | JPG / PNG |
| Formato video | MP4 / MOV |
| Ratio | 9:16 — obligatorio |
| Resolución | 1080 × 1920 px |
| Duración máxima video | 15 segundos por slide (para videos más largos, usar múltiples slides) |
| Duración imagen | 7 segundos por slide (Instagram default) |
| Zona segura | Dejar 250px libres arriba (interfaz de perfil) y 250px abajo (barra de respuesta) |
| Zona del texto | Solo el 60% central de la pantalla es zona segura para texto importante |
| Peso máximo imagen | 30 MB |
| Peso máximo video | 4 GB |

### Stories — Stickers de interacción
| Tipo | Límite de caracteres |
|---|---|
| Encuesta (Poll) | Pregunta: 106 chars. Respuesta: 24 chars cada una |
| Preguntas | Pregunta: 106 chars. Sin límite en respuestas. |
| Slider emoji | Pregunta: 106 chars |
| Countdown | Texto: 50 chars. Fecha: configurable |
| Quiz | Pregunta: 130 chars. Respuestas: 30 chars cada una |

---

### Reels
| Spec | Valor |
|---|---|
| Formato | MP4 / MOV (H.264 o H.265) |
| Ratio | 9:16 recomendado. Mínimo 1.91:1, máximo 9:16 |
| Resolución | 1080 × 1920 px |
| Duración | 15–90 segundos (para esta campaña: 20–45 segundos) |
| FPS | 30fps mínimo |
| Zona segura | 250px arriba y 350px abajo (más interfaz que Stories) |
| Cover image | 1080 × 1920 px (imagen estática para el feed) |

### Reels — Caption
| Spec | Valor |
|---|---|
| Límite de caracteres | 2.200 caracteres |
| Visible sin "ver más" | ~125 caracteres (las primeras 2–3 líneas) |
| Hashtags | 3–10 (Instagram reduce reach con más de 10 en un Reel) |

---

### Feed Posts (foto/carrusel)
| Spec | Valor |
|---|---|
| Formato cuadrado | 1:1 — 1080 × 1080 px |
| Formato retrato | 4:5 — 1080 × 1350 px (recomendado: ocupa más pantalla) |
| Formato paisaje | 1.91:1 — 1080 × 566 px (no recomendado para esta campaña) |
| Slides en carrusel | Mínimo 2, máximo 20 |
| Peso máximo por imagen | 30 MB |
| Formato | JPG (para fotos), PNG (para diseños con texto/fondo plano) |

### Feed Posts — Caption
| Spec | Valor |
|---|---|
| Límite de caracteres | 2.200 caracteres |
| Visible sin "ver más" | ~125 caracteres |
| Hashtags en carrusel | 5–15 (en el caption o en primer comentario) |
| Estrategia de hashtags | Primera línea del caption: el hook. Última línea: los hashtags. |

---

### Instagram Stories — Límite de texto en el diseño
- Texto legible mínimo: **32sp (Android) / 34pt (iOS)** equivalente en el diseño.
- Para Bebas Neue en títulos: mínimo 80px sobre resolución 1080px.
- Para Inter en cuerpo: mínimo 45px sobre resolución 1080px.
- Nunca texto blanco sobre fondo blanco fotografía sin overlay.

## FACEBOOK

### Posts en grupos (orgánico)
| Spec | Valor |
|---|---|
| Texto | Sin límite técnico, pero óptimo: 300–500 palabras |
| Visible sin "ver más" | ~60–80 palabras (varía por dispositivo) |
| Imagen opcional | 1200 × 630 px (ratio 1.91:1) o 1:1 |
| Frecuencia | Máximo 1 vez por semana por grupo |
| Formato imagen | JPG / PNG |

### Ads en Facebook Feed
| Spec | Valor |
|---|---|
| Primary text | Hasta 125 caracteres sin truncar. Máximo: 2.200 caracteres. |
| Headline | Máximo 40 caracteres (se trunca en muchos formatos) |
| Descripción del link | Máximo 30 caracteres |
| Imagen estática | 1200 × 628 px (ratio 1.91:1). Alternativa cuadrada: 1080 × 1080 px |
| Video | 1280 × 720 px mínimo. Ratio 9:16 para Stories/Reels de Meta. 16:9 para feed. |
| Duración video | 15 segundos (Stories). Hasta 240 minutos (feed, aunque para esta campaña: 20–30s) |
| Regla del 20% texto | Ya no es obligatorio, pero se recomienda menos del 20% de la imagen cubierta por texto |
| CTA del botón | "Registrarse", "Más información", "Saber más" — estos 3 son los más apropiados |

### Facebook Stories (Ads)
| Spec | Valor |
|---|---|
| Ratio | 9:16 |
| Resolución | 1080 × 1920 px |
| Duración | 15 segundos |
| Zona segura | 250px arriba y 250px abajo |

## X / TWITTER

### Tweets
| Spec | Valor |
|---|---|
| Caracteres | 280 máximo (con imágenes o links, el link ocupa 23 caracteres fijos) |
| Con link | 280 − 23 = 257 caracteres de texto |
| Con imagen + link | 280 − 23 = 257 caracteres de texto (la imagen no resta caracteres) |
| Thread | Sin límite de tweets en el thread. Para esta campaña: 8 tweets. |

### Imágenes en X
| Spec | Valor |
|---|---|
| Imagen única | 1200 × 675 px (ratio 16:9). Se muestra completa en feed. |
| Imagen cuadrada | 1200 × 1200 px. Se recorta a 16:9 en feed pero se ve completa al tap. |
| Hasta 4 imágenes | Se muestran en grid. Cada una: 1200 × 1200 px recomendado. |
| Formato | JPG / PNG / GIF / WEBP |
| Peso máximo | 5 MB (JPG/PNG), 15 MB (GIF) |

### Videos en X
| Spec | Valor |
|---|---|
| Duración | Hasta 140 segundos |
| Resolución | 1280 × 720 px mínimo. 1920 × 1080 px recomendado. |
| Ratio | 16:9 (horizontal) o 1:1 (cuadrado). El 9:16 vertical también funciona. |
| Formato | MP4 / MOV |
| Peso máximo | 512 MB |
| FPS | 40fps máximo |

## CHECKLIST ANTES DE PUBLICAR

**Para cada pieza:**
- [ ] Resolución correcta según plataforma
- [ ] Texto fuera de zonas no seguras (arriba/abajo en Stories)
- [ ] Subtítulos en videos (mínimo en formato quemado/burned in)
- [ ] Caption revisado: sin errores de tipeo, hashtags al final
- [ ] Link funcionando (si hay CTA)
- [ ] Audio: volumen normalizado, sin clipping
- [ ] Mobile preview: ver cómo se ve desde el teléfono antes de publicar
- [ ] Nombre de archivo ordenado: [semana]-[plataforma]-[variante]-[fecha].mp4

**Para ads pagados:**
- [ ] Audience segmentada correctamente
- [ ] Presupuesto diario configurado
- [ ] Pixel de conversión (si hay) activado
- [ ] Variante A/B configurada (si es test)
- [ ] URL de destino con UTM parameters:
  ```
  ?utm_source=[plataforma]&utm_medium=[tipo]&utm_campaign=100capitanes&utm_content=[variante]
  ```

### Ejemplo de UTM completo:
```
https://fulbitoapp.com/registro?utm_source=instagram&utm_medium=story&utm_campaign=100capitanes&utm_content=variante-a-hook
```
